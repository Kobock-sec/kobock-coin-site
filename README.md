# KOBОCK coin landing page

A responsive static website for the KOBОCK meme coin concept.

## Files
- `index.html` — page content
- `styles.css` — responsive visual design
- `script.js` — tiny year updater
- `assets/kobock-mark.svg` — original vector emblem included with the site

## Before publishing
1. Confirm you are entitled to use the KOBОCK name and logo for this token.
2. After token creation, replace the disabled placeholder links in `index.html` with the verified Pump.fun token page and official social links.
3. Do not add claims about guaranteed returns, utility, partnerships, or community size unless they are accurate.
4. Publish as a static site using GitHub Pages or Cloudflare Pages.

## Publish with GitHub Pages
1. Sign in at https://github.com/ and create a new **public** repository (for example `kobock-coin-site`).
2. Upload the contents of this folder to the repository root (upload the files and the `assets` folder, not the outer folder).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait for GitHub to publish the site. The public URL will be shown in the Pages settings, usually `https://YOUR-USERNAME.github.io/kobock-coin-site/`.

The included page is informational only and does not provide wallet connection, token trading, or financial advice.
